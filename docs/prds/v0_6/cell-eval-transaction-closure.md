## 4. Resolved design decisions

- **D1 — One eval-context module with a closed constructor set, and a type that makes a cell context unforgeable (critic M5).** `cell_eval_ctx.rs` owns every engine `EvalContext` construction. The types (`CellEvalCtx`, `CellValue`, `expr_ctx`, `eval_cell_guarded`) and the retype of the commit value leg arrive in θ, the earliest leaf that needs them; τ closes the constructor set, makes the base builder private, adds the allowlist rows and flips the status (fold-verify NEW 1). The capability-less base builder becomes a private fn there (`base_eval_ctx`); `eval_ctx_with_meta` disappears from `lib.rs`. `cell_eval_ctx` returns a `CellEvalCtx<'a>` newtype (no `Deref` to `EvalContext`). The only way to obtain a committable evaluated value is `eval_cell_guarded(&CellEvalCtx, cell, expr) -> Result<CellValue, CellPanic>` (D9), and the commit primitive's value leg accepts a `CellValue`, never a raw `Value`. Values that legitimately reach a cell without evaluation enter through named provenance constructors (`CellValue::{solved, overridden, inactive_undef, reserved, compute_output, minted, overlay}` — `minted` for the R3d/R3e symbolic selector and geometry-handle mint in `elaborate_cell` and σ's mint/hydrate sites, `overlay` for the annotation post-pass's `CacheLeg::Skip` overlay), each counted by row E9. When θ retypes a commit site whose value fits none of them, θ stops and reports it: adding a constructor is a design change to §5.1. The non-cell constructors form a closed, named set, each requiring exactly the capabilities its purpose carries (§5.1): `op_arg_eval_ctx` (geometry-op arguments, realization-input hashes, compute redispatch arguments), `contract_probe_eval_ctx` (`record_op_contract_failures`, which needs determinacy and the undef-cause sink), and `probe_eval_ctx` (read-only probes: `objective_term_contributions`, annotation-argument kind checks, DFM diagnostic folding, `compute_changed_realizations`). They return plain `EvalContext`s, so their results cannot be committed to a cell; each has a ratchet row whose target is its named-function allowlist (§5.10 E1a–E1c). Helpers that evaluate sub-expressions inside a cell eval (`build_sampled_field`) receive the inner context through `CellEvalCtx::expr_ctx()`, counted by row E1d. **Classification rule** for each of the 61 + 3 sites (§10 lists them by function): result committed to a value cell or deciding a cell's activation → `cell_eval_ctx`; otherwise the narrowest probe/op constructor.

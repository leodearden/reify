Binding vocabulary:

- **producer-upstream**: a hard `add_dependency` edge delivers the capability. The edge is either an intra-batch leaf or a named task. Out-of-batch producers carry no delivered_check here.
- **existing-substrate**: the capability is on main today. It is cited by symbol and was verified by `git grep` or a probe at drafting.

Verdicts:

- **PASS**: the binding is green.
- **FAIL**: the binding blocks the batch until it is resolved, and the failure class is named.
- **OPEN**: a decision the leaf itself makes. It is not a green G3 binding, and it does not block. Each OPEN row is listed under "Blocking" so the lead can pin it instead.

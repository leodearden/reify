# U+00B7 MIDDLE DOT (`·`) as unit_mul — task #5784, angle-units leaf κ
#
# PRD docs/prds/v0_6/angle-units-surface-convergence.md cluster C, ratified
# decision 7a. The external scanner's UNIT_MUL_OP token now fires on ASCII `*`
# OR U+00B7, both gated identically by `is_unit_start` (scanner.c). `·` is the
# SI-conventional multiply, and `Display for DimensionVector` emits it — so
# accepting it is what makes `reify eval` output such as `7850 kg·m^-3` readable
# back in. `·` and `*` lower to the SAME `UnitExpr::Mul`, hence the identical
# trees below and their `*`-spelled twins earlier in this file.
#
# THESE ROWS ARE DOCUMENTATION, NOT ENFORCEMENT. No gate anywhere executes this
# corpus: scripts/verify.sh never invokes `tree-sitter test`, and
# tree-sitter-reify/package.json has no scripts block. The LIVE regression signal
# for everything below is tree-sitter-reify/tests/unit_middot_mul_grammar_tests.rs,
# which cargo nextest runs.
#
# Every expected tree here was transcribed from a real parse, never hand-written,
# and verified green with `tree-sitter test` (10/10 at the time of writing; run
# `bash scripts/tree-sitter-generate.sh` first, or it aborts with "No language
# found" — the generated parser is gitignored).
#
# The `(UNEXPECTED 183)` tokens in the negative rows (183 = 0xB7) are a GLR
# error-recovery RENDERING ARTIFACT, not a language contract — only the presence
# of an error is contractual. They must be re-pinned from the `tree-sitter test`
# diff ONLY: `tree-sitter parse` renders the same node as a nested
# `(ERROR (ERROR))`, and copying that form in produces a pin that fails
# `tree-sitter test`. See the same warning, and the same artifact drifting across
# grammar changes, in test/corpus/imaginary_literal.txt:11-22.

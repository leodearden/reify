; U+00B7 MIDDLE DOT (`·`) as unit_mul — task #5784, angle-units leaf κ
;
; PRD docs/prds/v0_6/angle-units-surface-convergence.md cluster C, decision 7a.
; UNIT_MUL_OP fires on ASCII `*` OR U+00B7, both gated by `is_unit_start`
; (scanner.c) and both lowering to the SAME `UnitExpr::Mul` — so the rows below
; are identical to their `*`-spelled twins earlier in this file.
;
; DOCUMENTATION, NOT ENFORCEMENT: no gate executes this corpus (scripts/verify.sh
; never invokes `tree-sitter test`, and package.json has no scripts block). The
; live regression signal for everything below is
; tree-sitter-reify/tests/unit_middot_mul_grammar_tests.rs, which cargo runs.
;
; Two rules when editing this file, both learned the hard way:
;   1. Comments are `;`-prefixed, NEVER `#`. Everything between a row's `---` and
;      the next `===` is that row's expected tree, and `#` is not a comment
;      there — a `#` header is absorbed into the row ABOVE and breaks THAT row.
;   2. Re-pin the `(UNEXPECTED 183)` tokens (183 = 0xB7) from a `tree-sitter test`
;      diff ONLY. They are a GLR error-recovery rendering artifact, not a language
;      contract — only the presence of an error is contractual — and
;      `tree-sitter parse` renders the same node as a nested `(ERROR (ERROR))`,
;      which produces a pin that FAILS under `tree-sitter test`.
; Both idioms also appear in test/corpus/imaginary_literal.txt:1-30.
;
; Every expected tree here was transcribed from a real parse, never hand-written.
; Check manually on the FULL corpus — a filtered run hides a broken neighbour:
;   bash scripts/tree-sitter-generate.sh && cd tree-sitter-reify && tree-sitter test
; (without the generate step: "No language found" — the parser is gitignored).
;###############################################################################
